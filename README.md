inside a piano:

> I'm inside the piano now. Every wrong note is mine. The pianist blames the acoustics. I take the credit.

104 characters, one line, tournament winner over 12 candidates (DESIGN.md).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`
with no trailing newline. No clock, no randomness, no network.
